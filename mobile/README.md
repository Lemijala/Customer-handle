# Woyyuu Tech Mobile App

Flutter mobile app for Woyyuu Tech — mirrors the web app.

## Setup

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Run `flutter pub get` in this directory
3. Copy project images from `../client/public/projects/` to `assets/images/`
4. Copy `../client/public/logo.png` to `assets/images/logo.png`
5. Run `flutter run`

## Screens
- Home — hero, stats, what you get, testimonials
- About — our story, core values, team
- Experience — roadmap timeline
- Projects — project cards
- Services — service list with alternating layout
- Contact — contact form connected to the same backend
